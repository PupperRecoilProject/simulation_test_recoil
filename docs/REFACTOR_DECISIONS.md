## 概念筆記（本輪解釋過、留存備查）
- **Typer**：建 CLI 程式的 Python 函式庫（不是終端機本身）。CLI 仍在 PowerShell 跑；
  Typer 之於終端機 UI ≈ NiceGUI 之於網頁 UI——都是「拿來蓋介面的工具」。用型別註記寫，省去手動解析 argv。
- **RLock vs 分層鎖**：`threading.Lock` 非重入（同執行緒重拿會自我死鎖）。RLock 可重入但掩蓋結構問題；
  分層＝公開方法自鎖、私有 `_locked` 方法假定持鎖，契約寫進命名、自我說明（採用此案）。
- **LRU（Least Recently Used）**：快取淘汰策略。設上限，滿了丟「最久沒被使用」的項目，保留熱項；用於 terrain_cache 有界化。
